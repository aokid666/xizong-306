# 西综真题 · 刷题本

西医综合（306）刷题站：**6,749 道历年真题（1988—2026）+ 1,127 道天天师兄模拟题 + 175 题易错小结**。
纯静态页面，无后端、无账号；数据默认存在本机浏览器，可选择开启 GitHub 云端同步。

> 白纸黑字、克制配色：正确绿、错误红，没有多余装饰。

---

## 快速开始

**方式一：直接打开**
双击 `index.html` 即可（脚本都是普通 `<script>`，不依赖 fetch 和模块加载）。

**方式二：本地静态服务（推荐，IndexedDB 可用）**

```bash
python -m http.server 8777
# 打开 http://127.0.0.1:8777/
```

**方式三：GitHub Pages**
推送到仓库后在 Settings → Pages 选择 `main` 分支根目录。

## 功能

### 分类与选题

| 维度 | 说明 |
| --- | --- |
| 按年份 | 1988—2026，逐年整套；可选「滚动（纸质卷）」「单题（左右切换）」，可选按题号或随机打乱 |
| 按科目 | 生理学 / 生物化学 / 病理学 / 内科学 / 外科学 / 人文精神（含执业医师人文真题，默认不计入年份套题） |
| 按章节 | 科目 → 章 → 节 → 知识点（节与知识点来自「医考帮分层刷题」） |
| 模拟题 | 天天师兄 12 套、1,127 题；**题号、顺序、题干、选项与原试卷逐一核对一致**，跨套重复的题只存一份 |
| 易错小结 | 天天师兄五科易错清单，175 题，全部可在真题库中找到 |
| 随机组题 | 自选科目、章节、分层、年份区间、题型、题量，可排除已标记 / 只抽没做过 / 只抽做错的 |

- **病例题成组**：共用题干的多小问（239 组）在抽取、打乱、作答、提交时始终是一个整体，只出现一个提交按钮；公共题干只显示一次。
- **B 型题两种形态**：默认逐题显示；在设置里打开「B 型题合并显示」后，同一组共用备选答案的题目合成一题、选项只列一次，按选项字母作答 —— 和纸质卷子一样。

### 作答

- **滚动模式**：像纸质卷子一样从头做到尾；支持「每题提交」「每 N 题一起提交」「整卷提交」。
- **单题模式**：左右切换（← → 键），底部固定上一题 / 下一题 / 答题卡。
- 提交后立即判分：正确选项绿底、错选红底、其余淡化，显示正确答案、你的答案与解析。
- **多选判定**：X 型题与多答案题目自动多选；「多选」标签固定排在最前面、黑底反白。
- **答题卡**：按 **A 型 / B 型 / C 型 / X 型** 分组显示，灰=已选未交、绿=对、红=错、红点=已标记，点击跳转。
- 断点续做：中途退出会保存进度，首页「继续上次」回到原题。

### 模拟题的两个答案

模拟题来自天天师兄讲义，答案取自《模拟题库(狂背用)》各章末的答案表。由于课堂讲解可能与讲义不同：

- 正常作答 → 提交 → 按当前「正确答案」判分；
- 点右上角 **「答」** 可以录入 / 订正这道题的正确答案（按课堂讲解），之后判分以订正后的为准；
- 订正结果会跟随云端同步，换设备也在。

### 解析

- 默认在题目下方折叠展开（`▸ 解析`）。
- 设置中可改为「侧边栏」显示：提交后自动从右侧滑出解析。

### 手写

- 卡片右上角 `✍` 进入手写模式，直接在题面上书写（笔 / 橡皮 / 黑红蓝 / 三档粗细 / 撤销 / 清空）。
- 笔迹按题目保存，退出、切换模式、刷新后仍在；窗口缩放时按比例重绘。

### 笔记

- `✎` 展开笔记区：文字 + 图片（Ctrl+V 直接粘贴截图、也可选文件），图片自动压缩、点击放大。

### 划线 / 高光 / 批注

- 选中任意题干、选项、病例题干、解析文字 → 浮动工具条：**高亮 / 划线 / 批注**。
- 批注以 `※` 角标显示，悬停看内容，点击可查看或删除。

### 标记与整理

- `★` 收藏；`⚑` 标记为 **过时 / 争议 / 烂题 / 超纲 / 待复习**。
- 「收藏 / 错题 / 标记 / 有笔记」四个列表，可一键把当前列表变成练习。
- 统计页：总体正确率、分科目进度、标记分布。

### 思维导图

- 导航「导图」：天天师兄五科思维导图 **272 页**，左侧目录（科目→章→节）直接跳页，顶部可搜导图内容与目录；
- 图上可以直接**手写**（笔/橡皮/三色/三档粗细/撤销/清空），也可以写**文字笔记**，都按「第 N 页」保存，和做题记录一样跟随云端同步；
- 做题时点卡片上的 **「图」** 按钮：可以选「侧边分屏（左题右图）」或「显示在题目下方」；导图按题目的科目+章节自动匹配对应页。

### 题目关联（对照模式）

- 卡片上的 **「链」** 按钮：搜索并关联相似的题，**双向**生效；
- 关联后卡片上方会出现 `关联 2019N52 ×` 这样的小标签，点一下就能展开看那道题的题干、答案和解析，也可以就地取消关联。

### 备份

- **导出备份 ZIP（含原图）**：`data.json` + `notes/<id>.png`，换设备用「导入备份 ZIP」一键恢复，图片原样还原。
- 导出 JSON：只有文字记录（体积小），不含图片。

### 云端同步（可选）

在「设置 → 云端同步」填入：

| 项 | 说明 |
| --- | --- |
| 仓库 | `owner/repo`，默认 `aokid666/xizong-306-data`（私有仓库，已创建） |
| 文件 / 分支 | 默认 `xizong.json` / `main` |
| 令牌 | GitHub fine-grained token，只勾选该仓库的 **Contents: Read and write** |

- 打开页面自动拉取一次；本地改动 4 秒后自动上传；切回页面时也会同步；顶栏 `☁` 可手动同步。
- 合并规则：作答记录 / 收藏 / 标记 / 笔记按时间取新；划线按 id 合并；手写取较新的一版；设置以本机为准。
- **笔记图片按原图同步**：每张图存成仓库 `notes/<id>.<png/jpg>` 一个文件（不做压缩、保留原始分辨率），只有新增/删除图片时才会上传；删除图片会在云端一起删除（墓碑记在主文件里）。本地另存一份压到 1400px 的缩略图用于列表显示，点开看原图。
- 令牌只保存在本机浏览器的 localStorage，不会写进导出文件。
- 图片较多时同步文件会变大（上限 18MB），超出会提示改用「导出备份」或减少图片。

## 数据来源

| 来源 | 用途 |
| --- | --- |
| 医考帮真题导出（顺序版），191 个 docx | 真题正文、选项、答案、解析、科目与章 |
| 医考帮分层刷题，2,820 个 docx | 章（更准确的归属）、节、知识点三级分层 |
| 西综近25年真题（章节版）5 个 PDF | 核对：抽出 4,287 个题号，与题库重合 100%，无额外题目 |
| 西综306章节版真题 18 个 PDF | 扫描合订本，内容同年份真题，未单独导入 |
| 十年真题（2016-2025）.pdf | B 型题「共用备选」版式的参照 |
| 天天师兄模拟题库(狂背用).pdf 等 10 个 PDF | 模拟题：题干与答案取自狂背用（含各章「本章答案」表），套卷题号/顺序按原试卷还原，逐题与原卷核对 |
| 27考研讲义：五科 易错小结（真题）.pdf | 易错清单：175 题，按科目映射到真题库 |

合并规则：

1. 真题唯一键 = `年份 + 试卷编号 + 题号 + 临床/基础类别`（2007 年病例部分分两类编号，分别保留）。
2. 顺序版与分层版互相补全：答案 / 解析以顺序版为准，缺失时取分层版；章节归属优先取分层版，缺失或为「超纲题 / 诊断学」等伪章时回退。
3. 病例题识别：同年份、题号连续、题干公共前缀相同；取最长公共前缀（截到最后一个句号）作为公共题干。
4. B 型题识别：同年份、题号连续、选项完全相同的题合成一组。
5. 模拟题：题干与答案以《模拟题库(狂背用)》的分章汇总为母本（它已把 10 个 PDF 的题合并、并标注了〔来源 原第 N 题〕），套卷顺序按该标注还原成原卷题号，再用原试卷 PDF 逐题核对。

   核对结果（按题号逐题比对题干与四个选项，忽略上下标排版差异）：

   | 套卷 | 原卷 | 站点 | 题号 | 题干 | 选项 |
   | --- | --- | --- | --- | --- | --- |
   | 生理阶段测试 | 62 | 62 | 全 | 一致 | 一致 |
   | 生化阶段测试 | 25 | 25 | 全 | 一致 | 一致 |
   | 病理阶段测试 | 51 | 51 | 全 | 一致 | 一致 |
   | 外科阶段测试 | 37 | 37 | 全 | 一致 | 一致 |
   | 内科阶段测试 | 116 | 116 | 全 | 一致 | 一致 |
   | 基础摸底 / 冲刺摸底 | 165 / 165 | 165 / 165 | 全 | 一致 | 一致 |

   说明：共用题干的病例题在原卷里只印一次题干、小问只写问句；站点按同样方式显示（题干一次 + 各小问），不再每题重复整段病史。
6. 易错小结：从讲义里抽出题号，映射到真题库（175/175 全部命中）。

```

js/session.js       做题引擎（滚动 / 单题 / 分组提交 / 答题卡 / 续做）

data/bank-s0..5.js  6 个科目的真题

```

### 数据格式

真题 `data/bank-sN.js`：`window.XZ.bank["生理学"] = [ ... ]`，每题一个数组：

```
[0] id        "2010-N57" / "2007-N174-L"（临床）/ "-J"（基础）/ "2018-U2-121"
[1] ci        章序号（对应 meta.subjects[].chapters 下标）
[2] sec       节（形如 "第1节 适应"，可能为空）
[3] kp        知识点（可能为空）
[4] year      年份
[5] num       题号
[6] type      A / B / C / X
[7] variant   "" / "C"（临床类）/ "B"（基础类）
[8] stem      题干（病例题每个小问都是完整题干，公共题干在渲染时自动推导）
[9] opts      [["A","选项文本"], ...]
[10] answer   "ABD"
[11] explain  解析
[12] cluster  病例组 id（"c12"）或空
[13] mid      "N" / "U1" / "U2" …
```

模拟题 `data/mock.js`：`window.XZ.mock = {subjects, sets, rows}`，每行
`[科目, 章, 节, 来源套卷, 原题号, 题干, [[A,文本],…], 答案, 是否多选]`。

## 已知限制

- 真题答案解析来自医考帮，个别老题可能与新版教材冲突 —— 这正是「标记为过时 / 争议」的用途。
- 模拟题答案取自讲义答案表，若课堂讲解有出入，请用「答」按钮订正；订正只影响判分，不改原始数据。
- 手写与笔记图片依赖浏览器本地存储；换浏览器或清缓存会丢失，重要内容请用「导出备份 ZIP」或开启云端同步（两者都含原图）。
- 单题模式下浏览器「后退」不会回到上一题（请用界面上的上一题按钮）。
- 病例题公共题干由最长公共前缀推导，极少数（11/239）差异过大会退化为每问显示完整题干。
- 15 道模拟题在 PDF 里没有选项（原文件如此），已自动跳过。
