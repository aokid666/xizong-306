# 西综真题 · 刷题本

西医综合（306）历年真题的离线刷题站：**6,749 题 / 1988—2026 / 6 个科目 / 239 组病例题**，纯静态页面，无后端、无账号、无网络请求，所有记录保存在本机浏览器。

> 白纸黑字、克制配色：正确绿、错误红，没有多余装饰。

---

## 快速开始

**方式一：直接打开**
双击 `index.html` 即可（脚本都是普通 `<script>`，不依赖 fetch 和模块加载）。

**方式二：本地起一个静态服务（推荐，IndexedDB 可用）**

```bash
python -m http.server 8777
# 浏览器打开 http://127.0.0.1:8777/
```

**方式三：GitHub Pages**
推送到仓库后在 Settings → Pages 选择 `main` 分支根目录即可。

## 功能

### 分类与选题

| 维度 | 说明 |
| --- | --- |
| 按年份 | 1988—2026，逐年整套；可选「滚动（纸质卷）」「单题（左右切换）」，可选按题号或随机打乱 |
| 按科目 | 生理学 / 生物化学 / 病理学 / 内科学 / 外科学 / 人文精神（含执业医师人文真题，默认不计入年份套题） |
| 按章节 | 科目 → 章 → 节 → 知识点（节与知识点来自「医考帮分层刷题」） |
| 随机组题 | 自选科目、章节、分层（节）、年份区间、题型、题量，随机抽取；可排除已标记 / 只抽没做过 / 只抽做错的 |

- **病例题成组**：共用题干的 3 个小问（共 239 组）在抽取、打乱、作答、提交时始终是一个整体，滚动与单题模式都只出现一个提交按钮。
- 题干公共部分只显示一次，三个小问只显示各自的问题。

### 作答

- **滚动模式**：像纸质卷子一样从头做到尾，每题都能作答；支持「每题提交」「每 N 题一起提交」「整卷提交」三种方式（首次在年份弹窗里选，之后可在设置里改）。
- **单题模式**：左右切换（也可用 ← → 键），底部固定上一题 / 下一题 / 答题卡。
- 提交后立即判分：正确选项绿底，错选红底，其余淡化；显示正确答案、你的答案与解析。
- **多选判定**：X 型题与答案多字母的题目自动按多选处理（点选切换，不设上限）。
- 答题卡：一屏查看全部题号状态（灰=已选未交、绿=对、红=错、红点=已标记），点击跳转。
- 断点续做：中途退出会保存进度，首页「继续上次」可回到原题。

### 解析

- 默认在题目下方折叠展开（`▸ 解析`）。
- 设置中可改为「侧边栏」显示：提交后自动从右侧滑出解析，不打断做题视线。
- 解析正文同样支持划线高亮与批注。

### 手写

- 卡片右上角 `✍` 进入手写模式，直接在题面上书写（笔 / 橡皮 / 黑红蓝三色 / 三档粗细 / 撤销 / 清空）。
- 笔迹按题目保存，退出、切换模式、刷新后仍在；窗口缩放时按比例重绘。
- 手写层覆盖在题面上但不拦截鼠标，退出书写模式后仍可正常选择文字。

### 笔记

- `✎` 展开笔记区：文字 + 图片（支持 Ctrl+V 直接粘贴截图、也支持选择文件）。
- 图片自动压缩到 1400px 内，点击可放大。

### 划线 / 高光 / 批注

- 选中任意题干、选项、病例题干、解析文字 → 浮动工具条出现：**高亮 / 划线 / 批注**。
- 批注以 `※` 角标显示，鼠标悬停看内容，点击可查看或删除标记。
- 标记按题目持久化，并绑定原文片段（原文变动也能按文字重新定位）。

### 标记与整理

- `★` 收藏；`⚑` 标记为 **过时 / 争议 / 烂题 / 超纲 / 待复习**（可清除）。
- 「收藏 / 错题 / 标记 / 有笔记」四个列表，一键把当前列表变成练习。
- 统计页：总体正确率、分科目进度条、标记分布。
- 设置页：解析显示方式、提交方式、默认模式、字号、数据导出 / 导入、清空。

### 数据

- 作答记录、收藏、标记、笔记、手写笔迹都存在浏览器（IndexedDB，失败时降级 localStorage）。
- 导出 / 导入 JSON 备份；笔记图片因体积较大不包含在 JSON 内。

## 数据来源与合并

| 来源 | 用途 |
| --- | --- |
| 医考帮真题导出（顺序版），191 个 docx | 题目正文、选项、**答案**、**解析**、科目与章 |
| 医考帮分层刷题，2,820 个 docx | 章（更准确的章节归属）、**节**、**知识点** 三级分层 |
| 西综近25年真题（章节版）5 个 PDF（内科 / 外科 / 生化 / 生理 / 病理） | 核对用：抽出 4,287 个题号，**与题库重合率 100%，没有额外题目**，故未重复导入 |
| 西综306章节版真题 18 个 PDF（@cheryl雪 等） | 扫描版真题合订本，内容即上述年份真题，未单独导入 |

合并规则：

1. 题目唯一键 = `年份 + 试卷编号 + 题号 + 临床/基础类别`（2007 年病例部分分临床类与基础类，分别编号，故单独保留）。
2. 顺序版与分层版互相补全：以顺序版的答案 / 解析为准，缺失时取分层版；章节归属优先取分层版（分层版整理更准确），缺失或为「超纲题 / 诊断学」等伪章时回退到顺序版。
3. 病例题识别：同一年份、题号连续、题干公共前缀相同（前 40 字）的题目聚为一组；取最长公共前缀（截断到最后一个句号）作为公共题干，其余部分为各小问。
4. 共 6,749 题（6,440 个「年份 + 题号」），其中 239 组病例题包含 642 个小问，按「组」计为 6,346 组。

## 目录结构

```
index.html          单页入口
css/app.css         全部样式
js/store.js         本地存储（IndexedDB / localStorage）、modal/drawer/toast
js/bank.js          题库加载、索引、病例题成组、组题查询
js/card.js          题目卡片渲染、划线高亮、手写、笔记
js/session.js       做题引擎（滚动 / 单题 / 分组提交 / 答题卡 / 续做）
js/views.js         首页、年份、科目、组题、列表、统计、设置
js/app.js           启动与 hash 路由
data/meta.js        科目 → 章 → 节 → 知识点 索引、年份统计、病例分组表
data/bank-s0..5.js  6 个科目的题目数据
tests/              浏览器内自测页（selftest / uitest / preview）
```

### 题目数据格式

`data/bank-sN.js` 形如 `window.XZ.bank["生理学"] = [ ... ]`，每题是一个数组：

```
[0] id        "2010-N57" / "2007-N174-L"（临床）/ "-J"（基础）/ "2018-U2-121"
[1] ci        章序号（对应 meta.subjects[].chapters 下标）
[2] sec       节（形如 "第1节 适应"，可能为空）
[3] kp        知识点（可能为空）
[4] year      年份
[5] num       题号
[6] type      A / B / C / X
[7] variant   "" / "C"（临床类）/ "B"（基础类）
[8] stem      题干（病例题每个小问都是完整题干，公共题干在渲染时自动推导）
[9] opts      [["A","选项文本"], ...]
[10] answer   "ABD"
[11] explain  解析
[12] cluster  病例组 id（"c12"）或空
[13] mid      "N" / "U1" / "U2" …（试卷/单元标记）
```

`data/meta.js`：`window.XZ.meta = { subjects: [{name, code, chapters: [{t,p,z,n,sec:[{t,n,kp:[{t,n}]}]}], n}], years:[{y,n}], total, clusters:{cid:[nums]} }`

新增题目时：把条目 push 进对应科目的数组、更新 meta 的计数即可。

## 已知限制

- 题库里的答案与解析来自医考帮导出，个别老题可能存在争议或与新版教材不符 —— 这正是「标记为过时 / 争议」功能的用途。
- 手写与图片依赖浏览器本地存储；换浏览器或清缓存会丢失，重要内容请先导出。
- 单题模式下浏览器「后退」不会回到上一题（请用界面上的上一题按钮）。
- 病例题公共题干由最长公共前缀自动推导，极少数（11/239）题干差异过大会退化为每问显示完整题干。
